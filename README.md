# Instalasi Python

## 1. Memeriksa Instalasi Python

Sebelum mulai menggunakan Python, periksa terlebih dahulu apakah Python sudah terpasang pada komputer lokal.

Buka Terminal atau Command Prompt, kemudian jalankan perintah berikut:

```bash
python --version
```

Pada beberapa sistem operasi, perintah yang digunakan adalah:

```bash
python3 --version
```

Jika Python sudah terpasang, terminal akan menampilkan versi Python yang digunakan.

<img src="https://github.com/imammularif/Basic---Python/blob/main/image/1.png?raw=true" width="50%">

## 2. Menginstal Python

Jika Python belum terpasang pada komputer lokal, lakukan instalasi sesuai dengan sistem operasi yang digunakan, seperti Windows, macOS, atau Ubuntu.

Silakan kunjungi halaman resmi berikut untuk mengunduh Python:

[Instalasi Python – Python.org](https://www.python.org/downloads/windows/)

Pilih installer yang sesuai dengan sistem operasi, kemudian ikuti petunjuk instalasi hingga selesai.

Setelah instalasi, periksa kembali versi Python melalui Terminal atau Command Prompt:

```bash
python --version
```

atau:

```bash
python3 --version
```

## 3. Menyiapkan Code Editor

Setelah Python berhasil diinstal, siapkan Integrated Development Environment (IDE) atau code editor untuk menulis dan menjalankan program Python.

Dalam dokumentasi ini, saya menggunakan **Visual Studio Code (VS Code)** sebagai code editor.

Pastikan Python sudah tersedia dan dapat dikenali oleh VS Code sebelum mulai menjalankan program.

# Penggunaan Python

## 1. Membuat File Python

Untuk mulai menulis program, buat file baru dengan ekstensi `.py`.

Contoh nama file:

```text
hello_world.py
```

## 2. Menjalankan Program Pertama

Tuliskan perintah berikut di dalam file Python:

```python
print("Hello World!")
```

Perintah `print()` digunakan untuk menampilkan output atau teks ke layar.

<img src="https://github.com/imammularif/Basic---Python/blob/main/image/2.png?raw=true" width="50%">

## 3. Menjalankan Program

Simpan file, kemudian buka Terminal pada direktori tempat file tersebut disimpan.

Jalankan program menggunakan perintah:

```bash
python hello_world.py
```

Jika menggunakan `python3`, jalankan:

```bash
python3 hello_world.py
```

Output yang diharapkan:

```text
Hello World!
```
